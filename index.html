2D Wolfram-style Cellular Automata

  • Each cell on the grid is either a 1 or 0
  • Each cell has four neighbors: North, East, West, South
  • The neighborhood (NEWS) of each cell can be written as a 4-bit number from 0 (0000) to 15 (1111)
  • a Rule (a 16-bit number) maps each neighborhood to the cell's next value
